AFFARYETTE — VERSION CONNECTÉE À SUPABASE

Commencez par lire README-SUPABASE.txt.
Exécutez supabase-schema.sql dans Supabase > SQL Editor > New query > RUN.
Puis ouvrez le site avec VS Code Live Server (ou un serveur web local).

Cette version utilise Supabase Auth, Database et Storage.
Le panier reste dans le navigateur. La confirmation de commande enregistre une commande, mais aucun paiement en ligne n'est intégré.
Ne mettez jamais de Secret key/service_role dans le navigateur.
